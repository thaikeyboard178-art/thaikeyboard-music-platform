### Final implementation clarifications

The actual API layers are generation/random.ts, levels.ts, generator.ts, answerSignatures.ts and choices.ts; notation/projection.ts, VexFlowRhythm.ts and examples.ts. Phase1 canonical production/theory-test files remain byte-identical. The public index only adds Phase2 exports. A normal paired subdivision is not counted as newly introduced syncopation; the controlled syncopation budget counts off-pulse attacks whose coalesced span extends across a pulse. Level7 may reuse learned ties. Integrated vocabulary auditing is seed-independent once meter/tempo/bars are fixed. Level5 disallows cross-bar ties in BOTH generation and external level validation; a failing-before/fixed-after regression proves the policy guard.

Explicit four-option2/4 dots-only context is allowed to fail with InsufficientDistinctChoicesError rather than invent ambiguous filler; unspecified four-option dots/combined context defaults to4/4. Beamed notes are marked before drawing, dotted eighth/sixteenth beams stay within their pulse, internal barlines are single, and row-break ties use two partial arcs. Natural glyph layout includes reserved final flag/dot space and a uniform SVG viewBox transform, not independent horizontal stretching. Actual browser ink bounds use canvas glyph metrics; SVG text getBBox font em-boxes were not mistaken for clipped ink. None of these changes implement exercise UI or audio. Final source checks and evidence are preserved under evidence/phase2; GitHub handoff occurs only after successful checks. Stop at Phase2.
